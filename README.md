# ftproject

A new Flutter project.

This project is a Flutter application that integrates a public REST API to display product data dynamically. The app fetches data from the Fake Store API (https://fakestoreapi.com/products), parses the JSON response, and displays the products in a responsive GridView layout.

Each product card shows the product image, title, and price. The application is designed to work on both web and mobile platforms with a responsive layout that adjusts based on screen size.

The project demonstrates:

API integration using the http package

JSON parsing in Flutter

State management using FutureBuilder

Displaying dynamic data using GridView

Responsive UI design

This application serves as a basic example of integrating REST APIs in Flutter and presenting dynamic content in a clean user interface.
